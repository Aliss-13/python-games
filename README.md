# 🎮 Python Games

Welcome to my collection of Python games!

This repository brings together several personal projects developed during my self-directed learning journey in Python programming.

Each game has been an opportunity to explore new programming concepts, experiment with different mechanics, and improve my software development skills.


## 🛠️ Technical Skills

- **Python:** functions, data structures, control flow, and application logic
- **Game systems:** turn-based combat, inventory management, crafting, and progression
- **Algorithms:** random events, resource management, and decision-making
- **Software design:** code organization, modularity, and state management
- **Development tools:** Git, GitHub, and VS Code

  
## 📖 Documentation

Each project has its own README with additional information about its features, gameplay, and installation instructions.


## 📂 Projects

Projects are listed from newest to oldest, highlighting the evolution of my Python development skills.

### 🐉 [Funky Final Fantasy](https://github.com/Aliss-13/python-games/tree/main/7.%20FUNKY%20FINAL%20FANTASY) - You've got skills!

A text-based RPG featuring exploration, quests, equipment, character progression, and turn-based combat.

**Technical highlights:** modular code organization, event systems, combat management, and data-driven game mechanics.

### 🧙‍♀️ [Magique Boutique](https://github.com/Aliss-13/python-games/tree/main/5.%20MAGIQUE%20BOUTIQUE) - What sorcery is this???

A magical shop management game where players gather ingredients, craft products, manage sales, and complete quests.

**Technical highlights:** crafting systems, automated sales, progression mechanics, and event management.

### 🏝️ [Don't Starve PLS](https://github.com/Aliss-13/python-games/tree/main/4.%20DONT%20STARVE%20PLS) - Please don't...

A survival game where players explore, gather resources, craft equipment, and manage their needs while preparing to escape a hostile world.

**Technical highlights:** inventory management, crafting, survival statistics, and seasonal systems.

### 🥕 [Potager Pompélop](https://github.com/Aliss-13/python-games/tree/main/3.%20POTAGER%20POMPELOP) - You got to pompélop!

A farming and management simulation where players grow crops, fulfill orders, earn money, and unlock upgrades.

**Technical highlights:** resource management, progression systems, and time-based mechanics.

### 🍓 [Fruity Final Fantasy](https://github.com/Aliss-13/python-games/tree/main/2.%20FRUITY%20FINAL%20FANTASY) – The Original Prototype

The original prototype that laid the foundations for Funky Final Fantasy. A console-based RPG featuring character classes, statistics, and turn-based combat.

**Technical highlights**: early implementation of combat mechanics, character classes, and progression systems.

This project was later redesigned and expanded into Funky Final Fantasy.

### 🌲 [Dans la Forêt RPG](https://github.com/Aliss-13/python-games/tree/main/1.%20DANS%20LA%20FORET%20RPG) - This is where it all began.

My very first Python game! A text-based adventure set in a mysterious forest, featuring exploration, random encounters, and unexpected dangers.

**Technical highlights**: control flow, random events, player interactions, and basic game logic.

The project that started my Python development journey.
